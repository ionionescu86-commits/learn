# Mapper Excel si rapoarte

Aplicatie web statica pentru incarcarea unui fisier Excel sau CSV, maparea coloanelor pe o tabela standard si generarea unor rapoarte simple.

## Publicare pe GitHub Pages

1. Creeaza un repository public pe GitHub, de exemplu `mapper-excel-rapoarte`.
2. Incarca fisierele din acest folder in radacina repository-ului:
   - `index.html`
   - `README.md`
3. In GitHub, mergi la `Settings > Pages`.
4. La `Build and deployment`, alege:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
5. Salveaza. Dupa cateva minute, aplicatia va fi disponibila la:
   `https://UTILIZATOR.github.io/mapper-excel-rapoarte/`

Aplicatia ruleaza complet in browser. Fisierele incarcate nu sunt trimise catre un server.
